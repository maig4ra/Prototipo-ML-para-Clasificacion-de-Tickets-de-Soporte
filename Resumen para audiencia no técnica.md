Este sistema es un *"clasificador automático"* (basado en Inteligencia Artificial) diseñado para automatizar la categorización y derivación de consultas por correos electrónicos al sector de atención al cliente. Su objetivo principal es reemplazar la gestión manual para evitar la saturación en los departamentos de soporte. 

📌 ¿Qué hace este sistema?

1.	Lee el mensaje: Analiza el texto del correo que envió el cliente.
2.	Lo categoriza: Decide qué tipo de problema es (por ejemplo, si es un incidente técnico o solo una solicitud de información).
3.	Lo deriva: Decide a qué departamento o equipo de trabajo debe ser enviado para que lo resuelvan.
4.	Tiene una página web fácil de usar: El sistema te da un enlace de internet donde puedes pegar un texto de un cliente y ver cómo la inteligencia artificial lo clasifica automáticamente.
	
🎯 ¿Qué tan confiable es?

El sistema es bastante inteligente, ya que aprendió leyendo miles de ejemplos anteriores, pero tiene distintos niveles de acierto dependiendo de lo que se le pida:
•	Para adivinar el "Tipo de problema": Es muy bueno. Acierta aproximadamente el 90% de las veces.
•	Para adivinar el "Departamento correcto": Es bueno, pero un poco menos preciso. Acierta alrededor del 73% de las veces.
•	Para designar la “Prioridad”: Es buena, acierta alrededor del 75% de las veces.
Esto significa que es una herramienta excelente para hacer el trabajo pesado y rápido, pero sigue necesitando que los humanos den una mirada de vez en cuando.

🛑 ¿Qué NO sabe hacer el sistema?

Sus limitaciones y riesgos son:
1.	NO responde a los clientes: El sistema es un organizador, no un asistente de chat. Fue programado exclusivamente para leer y etiquetar correos. Sabe a dónde enviar el mensaje, pero no sabe redactar una respuesta, pedir disculpas ni solucionar el problema por sí mismo.
2.	NO es infalible: Como su precisión para derivar al equipo correcto es del 73%, significa que 1 de cada 4 mensajes podría terminar en el departamento equivocado. Requiere de revisión humana en estas excepciones.
3.	NO entiende datos que nunca ha visto: El sistema aprendió con un historial de datos específico. Si un cliente escribe en un idioma que el sistema no conoce, o usa palabras y quejas sobre un producto totalmente nuevo que no existía cuando el modelo fue entrenado, el sistema se confundirá y clasificará al azar o de forma incorrecta.
4.	NO funciona 24/7: Actualmente, esta herramienta es un prototipo. No está instalado en servidor profesional definitivo. Para que funcione, una persona tiene que "encender el motor" manualmente ejecutando unos pasos en la plataforma llamada Google Colaboraty. Si esa plataforma se cierra o se desconecta por inactividad, la página web del clasificador dejará de funcionar hasta que alguien la vuelva a encender.
