# Prototipo-ML-para-Clasificacion-de-Tickets-de-Soporte
Los departamentos de atención al cliente se saturan con miles de correos electrónicos y consultas diarias que deben ser categorizadas y derivadas manualmente. Este modelo clasifica las consultas por urgencia, tema (facturacion, falla tecnica, etc) y el estado emocional del ciente (por como escriben). Enfocado a grandes empresas para la automatizacion de procesos administrativos.
